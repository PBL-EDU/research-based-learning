## 5. 与方案的差异

| 项 | 方案 | 实际 | 原因 |
|---|---|---|---|
| 数据盘 | 100 GB 独立盘 | 无，暂用系统盘 59 GB | 实例未购数据盘；30 人规模够用 |
| Docker | get.docker.com 脚本 | apt `docker.io` + `docker-compose-v2` | Ubuntu 26.04 官方脚本未必适配 |
| 应用层 | 全部 Docker Compose | API 走 systemd，PG/Redis 走容器 | 减少镜像构建环节，先打通链路 |
| API 端口 | 由 Caddy 反代 | 暂由 SSH 隧道访问 | 域名未备案，不能起 80/443 |
| PG 端口 | 不发布 | 仅 `127.0.0.1:5432` | 宿主机 API 需要连 |

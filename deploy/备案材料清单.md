# ICP 备案材料清单（个人主体 · 腾讯云接入 · 四川通管局）

> 用途：照着填，减少驳回。**我不能替你点提交**——人脸核验和短信验证必须本人操作。
> 但下面每一栏该写什么，我都给到可直接复制的文案。

---

## 0. 前置条件（缺一不可）

| # | 条件 | 怎么确认 |
|---|---|---|
| 1 | 腾讯云账号已完成**个人实名认证** | 控制台右上角头像 → 实名认证 |
| 2 | 服务器已购买，且**包月 ≥3 个月**（备案要求） | 轻量实例详情页 |
| 3 | 域名 `dreamook.com` 已完成**实名认证满 3 个工作日** | 阿里云域名控制台 → 域名列表 → 实名状态 |
| 4 | 域名持有者 = 备案主体（都是你本人） | 阿里云实名信息页 |
| 5 | 域名后缀在工信部批复名单内（`.com` 在） | 已满足 |

> **域名不需要从阿里云转到腾讯云**。注册商（阿里云/万网）与接入商（腾讯云）是两套体系，腾讯云备案支持外部注册商域名，只要实名通过。

## 1. 主体信息（个人）

| 字段 | 填什么 |
|---|---|
| 主体类型 | 个人 |
| 姓名 | 你的真实姓名（与身份证一致） |
| 身份证号 | 与身份证一致 |
| 手机号 | 本人实名手机号，能接收核验短信 |
| 邮箱 | 常用邮箱，能收备案通知 |
| 通信地址 | 身份证地址或现居住地址（精确到门牌号） |

**上传材料**：身份证正反面照片（四角完整、无反光、不遮挡）。

## 2. 网站信息（最关键，决定会不会被驳回）

### 2.1 网站名称

**推荐**（任选一个，3 个字以上、不含敏感词）：

- `白日梦研究性学习笔记`
- `白日梦学习笔记`
- `白日梦文献阅读记录`

**绝对不要出现**：社区、论坛、博客、中国、中华、国家、XX 网、XX 在线、教育培训、课程、学院。

> 个人备案的网站名称不能让人误以为是机构或经营性网站。「社区」「论坛」会直接触发交互式服务审查。

### 2.2 服务内容

腾讯云备案系统里选 **「其他」**（不要选「博客/个人空间」以外的交互类选项）。

备注/描述文案（可直接复制）：

```
个人研究性学习笔记的整理与分享。用于记录文献阅读笔记与学习心得，
仅本人使用，非经营性，不提供论坛、评论等交互服务。
```

> 如果系统要求写得更详细，补一句「内容为个人原创笔记，不含教育培训、课程售卖等服务」。

### 2.3 网站负责人

个人备案时，网站负责人通常 = 主体本人。若填写他人，需要额外的授权书。

### 2.4 域名与服务器

| 字段 | 值 |
|---|---|
| 域名 | `dreamook.com` |
| 服务器 IP | 买完实例后从控制台复制 |
| 接入方式 | 腾讯云（轻量应用服务器） |

**上传材料**：域名证书（阿里云域名控制台可下载 PDF）。

| 阶段 | 谁做 | 时长 | 注意 |

## 4. 十个常见驳回原因（按踩坑概率排序）

| # | 原因 | 规避 |
|---|---|---|
| 1 | 网站名称含「社区/论坛/博客」 | 用「学习笔记」类名称 |
| 2 | 服务内容描述里出现「评论/交流/互动」 | 文案里明确写「不提供交互服务」 |
| 3 | 域名实名未满 3 个工作日 | 提前做，别等 |
| 4 | 域名持有者与备案主体不一致 | 阿里云实名信息核对 |
| 5 | 身份证照片模糊、反光、缺角 | 重拍 |
| 6 | 手机号非本人实名 | 用本人号码 |
| 7 | 通信地址不精确 | 写到门牌号 |
| 8 | 服务器购买时长不足 3 个月 | 买 1 年 |
| 9 | 网站名称与已备案网站重名 | 加前缀区分 |
| 10 | 涉及教育前置审批 | 避开「培训/课程/教学服务」措辞 |

## 5. 备案通过后要做的（我来做）

1. 阿里云 DNS 添加解析：`@` 和 `www` → 服务器公网 IP（A 记录）
2. 服务器上起 Caddy，自动申请 Let's Encrypt 证书
3. 验证 `https://dreamook.com` 与 `https://www.dreamook.com` 均 200
4. 把备案号放到门户页脚（法规要求）
5. 微信公众号 IP 白名单填入这台服务器的固定出口 IP

---

## 6. 备案期间的纪律

- **不要起 Caddy**：未备案域名的 80/443 被接入商拦截，Let's Encrypt 验证必然失败，反复重试会撞速率限制（同域名每小时 5 次），恢复要等一周。
- 内测走 SSH 隧道：`ssh -L 8080:127.0.0.1:8080 deploy@<IP>`，本机访问 `http://localhost:8080`。
- 域名解析可以提前配好，但**网站内容不要提前对外开放**。

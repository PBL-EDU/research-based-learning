## 2026-11-15 · 研究计划四阶段定稿

**讨论**

- 项目 = 研究计划；PBL 是其中一种模式
- 探究型与行动型合并为两种模式；职业探索归入探究型
- 写作不是社区的学习闭环，行动/实践/运用才是
- 《研究的方法》用于前半段（自我→问题→难题→项目设计→场域），行动研究用于后半段

**结论**

- 四阶段：立问 → 寻域 → 求证 → 知行
- 寻域交付「3 人 1 物/组织」；域 = 问题场域，不等于学科领域
- 写作作为贯穿线，不是独立阶段
- 新增 `docs/研究计划-四阶段.md`

**部署**

- 仅文档，无代码变更

## 2026-11-15 · 文献动作 A+D 落地（0.17.21）

## 2026-11-15 · 修复 CSS 断裂与输入框高度（0.17.11）

**反馈**

- 设置页贴边、被裁切
- 略读/精读/实践输入框太高
- 日历格式乱
- 领域→文献→卡片折叠线消失

**根因**

压缩统计样式时误删了 `@media (max-width: 420px)` 的收尾 `}`，导致其后的全部 CSS
（设置页留白、日历、折叠线、实践配色）在桌面端失效。

**改动**

- 修复 media 区块括号，CSS 重新平衡（129/129）
- 设置页左右各 32px 留白，输入框 `box-sizing: border-box`
- 输入框行数：略读 8→4，精读各字段 3→2，实践目标/步骤/标准压缩
- 部署 0.17.11

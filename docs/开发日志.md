# 开发日志

记录每一次需求、讨论、开发与部署。最新的在上。

## 2026-11-15 · 实践卡开发启动

**需求**

- 实践卡需要进入 Obsidian 日历（通过每日笔记锚点）
- 过程记录写在每日笔记
- 实践卡在文献条目内展开，与精读卡片用颜色区分
- 总览顶部放实践日历与今日实践
- 逾期 7 天判定为「卡住」

**讨论结论**

- 日历采用「自带月视图 + 每日笔记锚点」组合
- 日记位置读核心「日记」插件配置
- 日记中勾选计划任务后弹过程记录，取消则回滚勾选
- 步骤数据结构改为对象数组（当前无实践卡，无迁移成本）

**开发**

- 新增 `docs/实践卡设计.md`
- 契约：实践步骤改为 `{ text, done, doneAt? }[]`，新增 `scheduledFor` / `dueBy`，过程条目新增 `entryId` / `sourcePath`
- 新增 `core/practice-service.ts`：读核心日记配置、写/解析 `## 实践` 区块、更新卡片缓存
- 新增过程记录弹窗、实践总结弹窗；实践计划弹窗补日期与步骤
- 总览顶部新增月历与今日实践；文献内精读/实践分组，实践卡可展开看步骤与时间线
- 日记勾选计划行 → 弹过程记录，取消则回滚
- 每天一次实践提醒；逾期 7 天标「卡住」
- 版本目标：0.17.9

**部署**

- 已部署 0.17.9 到 Vault（`E:\Obsidian\学习与教育`）
- 自动补建每日笔记目录、套用核心日记模板
- 公开仓库暂未发版，等待试用反馈

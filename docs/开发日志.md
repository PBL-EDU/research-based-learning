## 2026-11-15 · 缩进、边框、设置页与日历（0.17.14）

**反馈（版本确认 0.17.13 后）**

- 领域比文献更靠右，层次不对
- 领域/文献外框消失，缺少区隔
- 设置页仍贴边/被裁切
- 弹窗输入框想从 3 行改回 5 行
- 日历星期栏与日期需要底色区分

**处理**

- 领域 caret 移到右侧，领域名从最左开始；文献缩进 18px，卡片再缩进
- 文献恢复 1px 细框与底色，领域之间加大间距
- 设置项改为上下堆叠（标签一行、控件一行），杜绝右侧裁切
- 弹窗 textarea 固定 88px（约 5 行）
- 日历：星期栏与日期格分别加底色，今天高亮
- 部署 0.17.14

## 2026-11-15 · 层级线与输入框兜底（0.17.12 / 0.17.13）

**反馈**

- 领域→文献→精读/实践缩进与折叠线仍丢失
- 设置页、三个弹窗输入框高度仍未解决

**处理**

- 折叠线同时用 `border-left` + `inset box-shadow`，避免被主题覆盖
- 设置页用 `.vertical-tab-content:has(.rlc-settings)` 兜底留白
- 输入框硬上限：弹窗 textarea 56px、单行输入 26px
- 设置页顶部显示「插件版本 0.17.13」，用于确认 Obsidian 实际加载的版本
- 日历拆成「星期行 + 日期格」两段，避免同一 grid 混排
- 部署 0.17.13

## 2026-11-15 · 修复 CSS 断裂与输入框高度（0.17.11）

**反馈**

- 设置页贴边、被裁切
- 略读/精读/实践输入框太高
- 日历格式乱
- 领域→文献→卡片折叠线消失

**根因**

压缩统计样式时误删了 `@media (max-width: 420px)` 的收尾 `}`，导致其后的全部 CSS
（设置页留白、日历、折叠线、实践配色）在桌面端失效。

**改动**

- 修复 media 区块括号，CSS 重新平衡（129/129）
- 设置页左右各 32px 留白，输入框 `box-sizing: border-box`
- 输入框行数：略读 8→4，精读各字段 3→2，实践目标/步骤/标准压缩
- 部署 0.17.11

## 2026-11-15 · 实践卡界面压缩（0.17.10）

**反馈**

- 文献动作 1–5 要在一行
- 统计 5 格要在一行，且压缩高度
- 日历压缩高度

**改动**

- 文献动作：四列改五列，标签缩短为「1 原文 / 2 整理 / 3 略读 / 4 精读 / 5 实践」
- 统计：五列一行，数值 14px、标签 9px、内边距压缩
- 日历：日期格 padding 与字号缩小，圆点 4px，标题与今日条间距压缩
- 部署 0.17.10 到 Vault

## 2026-11-15 · 实践卡开发启动

**需求**

- 实践卡需要进入 Obsidian 日历（通过每日笔记锚点）
- 过程记录写在每日笔记
- 实践卡在文献条目内展开，与精读卡片用颜色区分
- 总览顶部放实践日历与今日实践
- 逾期 7 天判定为「卡住」

**讨论结论**

- 日历采用「自带月视图 + 每日笔记锚点」组合
- 日记位置读核心「日记」插件配置
- 日记中勾选计划任务后弹过程记录，取消则回滚勾选
- 步骤数据结构改为对象数组（当前无实践卡，无迁移成本）

**开发**

- 新增 `docs/实践卡设计.md`
- 契约：实践步骤改为 `{ text, done, doneAt? }[]`，新增 `scheduledFor` / `dueBy`，过程条目新增 `entryId` / `sourcePath`
- 新增 `core/practice-service.ts`：读核心日记配置、写/解析 `## 实践` 区块、更新卡片缓存
- 新增过程记录弹窗、实践总结弹窗；实践计划弹窗补日期与步骤
- 总览顶部新增月历与今日实践；文献内精读/实践分组，实践卡可展开看步骤与时间线
- 日记勾选计划行 → 弹过程记录，取消则回滚
- 每天一次实践提醒；逾期 7 天标「卡住」
- 版本目标：0.17.9

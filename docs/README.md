# 研究性学习社区 · 架构设计

> 全新项目，尚无代码。本目录是开工前的设计基线：**边界、契约、决策**，不含实现。

## 这是什么

三名学生在一个 Obsidian 里完成研究闭环（文献综述 → 略读 → 精读卡片 → 实践 → 总结），把值得公开的卡片一键发布到社区，同学在网页上评论、点赞、转发，讨论又能被摘取回 Obsidian 变成新卡片。

三端：**Obsidian 插件**（工作台）、**服务器**（模板 + 发布 + 讨论）、**公众入口**（浏览与互动）。

## 一页纸

```
本地 Vault（真相） ──[学生点"发布"]──> 发布快照（服务器真相） ──> 门户阅读/讨论 ──> 摘取回本地
```

| 决策 | 一句话 |
|---|---|
| D1 本地优先 | Vault 是私域唯一真相，服务器只收快照，永不反向写 |
| D2 md + frontmatter | 存储格式即跨端契约，schema 版本化 |
| D3 模块化单体 | NestJS + PostgreSQL + OSS，不拆微服务 |
| D4 快照 + 修订链 | 改稿不破坏讨论，评论挂在卡片上而非版本上 |
| D5 AI 在插件端 | 私密内容不过服务器；服务端只做模板、渲染、审核 |

技术栈：TypeScript 全栈 / pnpm monorepo / NestJS + Prisma + PG16 + Redis + MinIO / Next.js 15 / Preact 插件 UI / Docker Compose + Caddy。

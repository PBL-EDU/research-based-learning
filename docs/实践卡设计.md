# 实践卡设计

> 状态：已确认，进入开发
> 决策日期：2026-11-15
> 对应版本：0.17.9

## 1. 定位

实践卡记录「做完一件事并复盘」，不是读书笔记。它从精读卡片的 Aha 立项，避免凭空立项。

链路：

```
领域 → 文献 → 精读卡片（Aha）→ 实践卡（计划 → 过程 → 总结）
```

## 2. 已确认的决策

| 主题 | 决定 |
|---|---|
| 日历 | 自带实践日历（B）+ 每日笔记锚点（A）组合 |
| 日历位置 | 总览顶部，默认展开整月 |
| 今日实践 | 总览顶部，日历下方；有今天/逾期才出现 |
| 实践卡位置 | 文献条目展开区内，与精读卡片分组显示 |
| 类型区分 | 精读蓝紫、实践青绿、逾期低饱和红；另加文字标签 |
| 过程记录 | 写在每日笔记，卡片内是汇总缓存 |
| 日记位置 | 读核心「日记」插件配置（folder + format），读不到用插件兜底 |
| 勾选联动 | 日记里勾选计划任务 → 弹过程记录；取消则回滚勾选 |
| 提醒 | 今日条 + 每天一次 Notice + 日记同步 + 逾期提示 |
| 逾期阈值 | 7 天无新过程记录 |
| 统计 | 卡片 / 精读 / 实践 三格 |
| 步骤 | 改为 `{ text, done, doneAt? }[]`（当前无实践卡，无迁移负担） |

## 3. 数据模型

```ts
PracticePlan = {
  goal: string
  steps: { text: string; done: boolean; doneAt?: IsoDateTime }[]
  resources: string[]
  scheduledFor?: "YYYY-MM-DD"
  dueBy?: "YYYY-MM-DD"
  successCriteria: string[]
}

PracticeProcessEntry = {
  entryId: string
  date: IsoDateTime
  what: string
  evidence?: string
  obstacle?: string
  adjust?: string
  sourcePath?: string
}

PracticeCardV1 = {
  ...信封
  plan: PracticePlan
  process: PracticeProcessEntry[]   // 缓存，可由日记重建
  summary?: PracticeSummary
  linkedCards: string[]
}
```

## 4. 每日笔记格式

````markdown
## 实践

- [ ] 访谈 3 位学生 · 计划今天
  <!-- rlc-plan: card=550e8400-... -->

- **完成第 1 位访谈** · 11-18
  <!-- rlc-process: card=550e8400-... entry=7c1f... -->
  - 证据：录音 12 分钟
  - 阻碍：老师临时换课
  - 调整：改约周三下午
````

规则：

- `## 实践` 区块内只追加，不覆盖其他内容
- 标记注释是解析锚点，阅读视图不可见
- 同一天同一张卡只写一条计划行；过程条目按 `entryId` 去重
- 解析失败跳过该条，不抛错

## 5. 界面

### 总览顶部

```text
实践日历（月视图，圆点：有计划 / 有记录 / 逾期）
今日实践（今天 + 逾期，点击展开对应实践卡）
领域列表 …
```

### 文献展开区

```text
▾ The voice of emotion…
  精读卡片 2
   ● 声音里的情绪线索        海报  立项  发布
   ● 情绪的两条通路          海报  立项  发布
  实践卡片 1
   ▸ 访谈 3 位学生    进行中 · 下次 11-20 · 过程 2
```

实践卡展开：

```text
▾ 访谈 3 位学生                 进行中 · 下次 11-20
   目标：…
   ☑ 联系 3 位学生家长
   ☐ 完成访谈
   ☐ 整理成 3 条结论
   [＋ 记录今天]  [写总结]

   过程（来自每日笔记）
   11-18  完成第 1 位访谈          日记 ↗
          证据：录音 12 分钟
```

### 颜色

| 类型 | 变量 | 用途 |
|---|---|---|
| 精读 | `--rlc-accent` | 圆点、左侧细线、标签 |
| 实践 | `--rlc-practice` | 圆点、左侧细线、标签 |
| 逾期 | `--rlc-danger` | 日期、卡住提示 |

## 6. 提醒规则

| 层级 | 触发 | 频率控制 |
|---|---|---|
| 今日条 | 打开库 | 常驻，无内容隐藏 |
| Notice | 当天第一次打开 | 每天最多一次 |
| 日记同步 | 当天第一次打开 | 幂等 |
| 逾期提示 | 7 天无过程记录 | 每卡每天最多一次 |

## 7. 容错

- 日记删除：卡片缓存保留记录，重建时提示差异
- 格式改坏：跳过该条；提供「检查实践记录」命令
- 日记插件未配置：使用插件设置兜底

## 8. 开发顺序

1. 契约
2. 每日笔记服务
3. 三个弹窗（计划 / 过程 / 总结）
4. 总览（日历、今日条、分组、颜色）
5. 勾选联动与提醒
6. 测试、构建、部署

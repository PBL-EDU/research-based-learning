# 研究计划 · 四阶段模型

> 状态：已确认（2026-11-15）
> 理论来源：《研究的方法》（墨磊宁、雷勤风）为主，行动研究与 PBL 为补充
> 适用：探究型 / 行动型研究计划

## 1. 为什么是这四个阶段

《研究的方法》的核心是「以自我为中心」：从自己出发，经过话题 → 问题 → 难题，再进入领域、设计项目。
但它以「写作」收尾；本社区的学习闭环是**行动/实践/运用**，所以第四阶段改为「知行」。

```
立问 → 寻域 → 求证 → 知行
  ↑                    │
  └──── 新问题 ← 复盘 ─┘
```

## 2. 四阶段

| 阶段 | 副标题 | 核心问题 | 交付物 |
|---|---|---|---|
| **立问** | 从自己出发，把话题变成真问题 | 我关心什么？我的问题是什么？难在哪？ | 问题陈述 + 难题一句话 |
| **寻域** | 画出问题场域：谁在回答、谁在实践、谁在受益 | 谁也在关心？他们知道什么、争什么？ | 3 人 + 1 物/组织 + 场域地图 |
| **求证** | 设计研究，收集证据，形成洞察 | 我怎么做？证据够不够？能得出什么？ | 一页计划 + 证据表 + 一个洞察 |
| **知行** | 把洞察用出来，行动后复盘 | 用在哪里？发生了什么？下一步问什么？ | 一次真实行动 + 反馈 + 复盘 + 下一个问题 |

## 3. 各阶段细则

### 3.1 立问

- 自我搜索：我在意什么？我有什么偏见/假设？
- 话题 → 一组具体问题
- 问题诊断：具体、中性、可回答
- 假设浮出：我原本以为答案是什么？
- 找难题：这些问题背后共同的张力
- 小试（可选）：用一点原始资料/一次访谈/一次观察调教问题

完成条件：

- 问题陈述写清楚
- 难题能用一句话说出「为什么难/为什么是我」
- 模式（探究/行动）与场景选定

### 3.2 寻域

不是找朋友，也不是选学科，而是画出**问题场域**：

- **学科领域**：制度化的学科/专业（心理学、社会学……）
- **问题场域**：一个问题牵连的人、组织、材料、实践
- **寻域**：画出问题场域的动作

固定交付「3 人 1 物/组织」：

| 项 | 要求 |
|---|---|
| 3 人 | 至少覆盖 2 类：研究者 / 实践者 / 亲历者 |
| 1 物/组织 | 关键文献、报告/政策、机构/项目、作品/产品、数据集，任选其一 |
| 产出 | 场域地图 + 一段「他们在争什么」 |

### 3.3 求证

- 设计：资料/对象、方法、伦理、成功标准、时间
- 一页研究计划（不写正式开题报告）
- 收集证据：精读卡、访谈、观察、实践
- 连点成线：证据 → 主张/洞察
- 检查反证与局限

完成条件：

- 一页计划完成
- 至少 3 条有效证据
- 一个能说清的洞察/主张

### 3.4 知行

三个层级任选其一：

| 层级 | 做法 | 例子 |
|---|---|---|
| 用在自己 | 改变一个做法/习惯 | 用情绪命名替代压抑，记录两周 |
| 用在他人 | 帮一个人/教一个人 | 把结论讲给同学，观察是否使用 |
| 用在场景 | 改造流程/活动/产品 | 重设计班级心理角的使用方式 |

完成条件：

- 至少 1 次真实行动
- 收集反馈/观察
- 复盘：什么有用、什么没用
- 长出下一个问题

## 4. 两种模式

| 阶段 | 探究型 | 行动型 |
|---|---|---|
| 立问 | 我的问题/难题 | 我想改变什么/为什么是我 |
| 寻域 | 文献与同类研究 | 实践者、利益相关者、受影响的人 |
| 求证 | 资料 → 论证 | 计划 → 行动 → 观察 → 调整 |
| 知行 | 回答、应用与复盘 | 改变、影响与复盘 |

## 5. 贯穿线

- **反思与修订**：阶段可回退，不锁死
- **写作**：记录、表达、对话，不是终点；作品集是行动的证据册

## 6. 与产品的关系

- 研究计划在「领域综述略读之后」立项
- 项目字段：`mode`（inquiry/action）、`scene`、`title`、`question`、`problem`、`summary`、`reflection`
- 阶段进度由字段与卡片自动推导，不手动打勾
- 门户作品集按「问题 → 场域 → 证据 → 行动 → 复盘」组织
- 实践卡是「知行」阶段的主要证据

## 7. 未定事项

1. 寻域的「3 人 1 物」是否为发布硬门槛
2. 知行阶段是否要求「下一个问题」必交
3. 阶段是否允许自由回退，还是只提示
4. 行动型是否要求导师评语才能公开
5. 门户首版先做公开作品集，管理端组装

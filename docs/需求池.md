## R-001 · 领域文献综述（详尽版）

| 项 | 内容 |
|---|---|
| 提出时间 | 2026-11-14 |
| 状态 | **暂不开发**（仅登记） |
| 提出人 | denghao |
| 影响模块 | Obsidian 插件 · AI 综述生成 |

**现状**：点「＋ 领域」生成的综述是**结构化概览**——争论点 / 2–4 条脉络 / 研究空白 / 下一步读什么 + 6–10 篇候选文献。够用来挑文献，但不够当「领域综述」这类交付物。

**目标（待细化）**：详尽版应满足

1. 篇幅显著更长（预计 4000–8000 字），按研究脉络分节展开；
2. 每篇候选给出摘要级介绍，并说明它在综述中的位置；
3. 引用与出处一一对应，正文里能定位到候选清单的哪一条；
4. 可能需要分节写入多个文件，或在单文件内做长文档导航。

**暂缓原因**

- token 成本与生成时长高（当前 6–10 篇候选约 20–40 秒；详尽版预计数分钟）；
- 需要先有足够的文献库与全文，否则只能靠模型泛写，风险高；
- 文件结构可能从「单文件」变成「目录 + 多文件」，等服务器端存储与检索就绪后再定，避免返工。

**重启条件**：领域内已录入 ≥10 篇文献，且服务器端能存全文/摘要（可做「只基于库内文献」的详尽综述）。

**影响面**：提示词、综述文件结构、候选清单格式、成本模型。
